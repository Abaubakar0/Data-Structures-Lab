# Attendance Management System (C++)
## 📌 Project Description

This is a simple C++ console-based program that manages attendance for participants. The user enters the total number of participants and specifies which participants are present. The program then displays the final attendance list showing who is present and absent.

## Language & Concepts Used
Language: C++
Concepts:
Dynamic Memory Allocation (new and delete)
Arrays
Loops
Conditional Statements
User Input/Output
