# Gun Simulation System
## Task Description

This C++ program simulates a gun shooting system with a magazine and bullet pool. Each shot decreases bullets from the magazine, and the system automatically reloads one bullet from the total pool if available. The simulation continues until all bullets are finished, while tracking total time taken.
