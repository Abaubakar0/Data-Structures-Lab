# IP Address Manager using Doubly Linked List

##📌 Task Description

This C++ program reads a list of IP addresses from a file and stores them in a doubly linked list. It then displays the IP addresses in both forward and backward order, demonstrating traversal in both directions.


## Language & Concepts Used
Language: C++
Concepts:
Doubly Linked List
File Handling (ifstream)
String Processing (stringstream)
Dynamic Memory Allocation
Forward & Backward Traversal
