# Secret Code Generator (C++)
## Task Description

This is a simple C++ console program that generates a "secret code" based on a user-input number. The code is calculated using the factorial of the given number. If a negative number is entered, the program displays an error message.

## Language & Concepts Used
Language: C++
Concepts:
Functions & Function Pointers
Loops (for loop)
Conditional Statements
Factorial Calculation
